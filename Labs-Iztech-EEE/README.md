# C Programming Laboratory

Laboratory exercises and larger programs developed for the C Programming course.

## Lab programs

| File | What it does |
|---|---|
| [`clab2.c`](clab2.c) | Course grade calculator for a two-exam or three-exam structure |
| [`c lab3.c`](c%20lab3.c) | Compares `sin(x)` and `cos(x)` with factorial-based series terms |
| [`clab4q2.c`](clab4q2.c) | Prints a star histogram of a random array |
| [`clab5yeni.c`](clab5yeni.c) | Fibonacci-style sequence from two user-given starting values |
| [`clab6.c`](clab6.c) | Prints an array and sorts it in descending order |
| [`clab7.c`](clab7.c) | Text processing: counts words, vowels and consonants in a sentence |
| [`clab8.c`](clab8.c) | Stores and prints a square pattern in a 2D array |
| [`clab9.c`](clab9.c) | Draws a sine wave of given magnitude and frequency as text |
| [`c lab soru.cpp`](c%20lab%20soru.cpp) | Prints the ASCII codes of the digits 0 to 9 |
